# KakaoWork Block Kit Tools

Slack Block Kit 메시지를 **카카오워크(Kakao Work)** 봇 메시지로 옮기고, 카카오워크 블록 메시지를 직접 조립·전송하는 웹 도구입니다. 빌드 과정 없이 브라우저에서 바로 동작합니다.

🔗 **바로 사용**: https://hilariochung.github.io/KW_SLK_Converter_Pilot/

> 카카오워크 공식 BI 팔레트(네이비 `#001469` 주력 + 옐로 `#ffe100` 포인트)를 따릅니다.

---

## 구성 — 두 개의 페이지

상단 내비게이션(`Converter` / `Maker`)으로 오갈 수 있습니다.

### 🔄 Converter — Slack → KakaoWork 변환기
이미 Slack용으로 만든 Block Kit JSON을 카카오워크 블록으로 변환합니다.

1. 좌측에 **Slack Block Kit JSON**을 붙여넣습니다.
2. **`변환하기`** 를 누르면 우측에 카카오워크 블록 미리보기 / KW JSON / 경고가 표시됩니다.
3. **`블럭킷 메이커로 보내기`** 로 변환 결과를 메이커로 그대로 넘겨 이어서 편집할 수 있습니다.

- **지원 봇 예시**: GitHub PR · Jira · PagerDuty · Sentry · Datadog · Jenkins · Stripe · Grafana (클릭하면 샘플 JSON이 채워집니다)
- **변환 규칙**: 카카오워크 스펙에 맞춰 자동 보정(action 최소 버튼 수, context 이미지 필수, 미지원 필드 경고 등).

### 🔧 Maker — 카카오워크 블록킷 메이커 (위지윅)
블록을 끌어다 조립해 카카오워크 봇 메시지를 직접 만듭니다.

1. 좌측 팔레트에서 블록을 클릭/드래그해 추가합니다.
2. 가운데에서 내용을 편집하면 우측 **미리보기 · JSON** 이 실시간 갱신됩니다.
3. **전송하기** 탭에서 App Key + 수신자 이메일로 바로 보내거나 cURL 가이드를 복사합니다.

- **블록 타입**: 헤더 · 텍스트 · 이미지(업로드/URL) · 구분선 · 버튼 · 버튼 그룹 · 설명 · 섹션 · 컨텍스트
- **버튼 동작**: 시스템 브라우저 / 인앱 브라우저 열기(`open_system_browser` / `open_inapp_browser`)
- **예시 템플릿**: 공지사항 · 승인 요청 · 일정 알림 · 시스템 점검 · 설문조사 요청 등
- **검증**: 카카오워크 스펙 위반(헤더 개수, 빈 버튼 URL, 필수 텍스트 등)을 실시간 배너로 안내.

## 전송 방법

메이커/컨버터의 **전송하기** 탭에서:

1. 카카오워크에서 발급한 **App Key** 입력 (브라우저 `localStorage`에만 저장, 서버 전송 없음)
2. **수신자 이메일** 입력 (쉼표로 복수 지정 가능 — 일괄 전송 스크립트 생성)
3. `messages.send_by_email` API를 사용 — 이메일만으로 대화방 생성 + 전송을 한 번에 처리

> ⚠️ 복수 일괄 전송 시 분당 쿼터(HTTP 429)에 걸릴 수 있어, 생성되는 스크립트는 `Retry-After` 대기 후 재시도하도록 되어 있습니다.

## 기술 / 배포

- **순수 정적 웹** — 빌드 스텝·외부 의존성 없음. `index.html`(컨버터) + `maker.html`(메이커) 단 두 파일.
- **GitHub Pages** 로 `main` 브랜치를 그대로 서빙 → `main` push 시 자동 배포.
- 로컬 실행: 저장소 루트에서 `python3 -m http.server 8000` 후 http://localhost:8000

## 프라이버시

- 입력한 App Key·메시지 내용은 **브라우저 안에서만** 처리되며 별도 서버로 전송되지 않습니다(실제 전송 시 카카오워크 API로 직접 호출).
- 본 서비스는 prototype이며, 전송 전 테스트 발송을 권장합니다.
